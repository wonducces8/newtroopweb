# Troop 1941

A responsive static site for Scout Troop 1941 in Leesburg, Virginia. It includes troop information, weekly meeting details, outdoor program highlights, a live Google Calendar, the troop slideshow, patrols, youth leadership, and Scoutmaster contact information.

## Preview

Open `index.html` in a browser, or run `npm start` to serve the site at http://localhost:4173.

## Content integrations

- The live Google Calendar and Slides embed are in `index.html`.
- Contact links reach Scoutmaster Matthew Grinnell at grinnell99@hotmail.com.
- Meeting information and the leadership roster currently reflect the previous Troop 1941 site and should be updated with the troop's current details.

The site uses plain HTML, CSS, and JavaScript, so it can be hosted on any static hosting service.
